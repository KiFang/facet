# Плагины Facet OS

Плагин — это JSON-манифест. Его устанавливают в редакторе: **Плагины → Управление плагинами → Установить из файла**.
Манифест сохраняется в конфигурации клуба (`club-schema.json`), поэтому плагин переносится вместе со схемой,
а его серверная часть попадает на сервер при экспорте (новая установка или обновление).

Готовый пример: [`examples/plugins/deadline-badge.json`](../examples/plugins/deadline-badge.json).

## Манифест

```jsonc
{
  "id": "deadline-badge",                 // a-z, 0-9 и дефис; не совпадает со встроенными плагинами
  "name": { "ru": "Метка «скоро»", "en": "“Soon” badge" },  // строка или { ru, en }
  "version": "1.0.0",                     // семантическая версия
  "description": "Что делает плагин",
  "author": "Имя или организация",        // необязательно
  "homepage": "https://…",                // необязательно
  "icon": "Bell",                         // значок из набора разделов
  "settings": [ /* параметры, см. ниже */ ],
  "contributes": { /* что добавляет плагин, см. ниже */ }
}
```

## Параметры (`settings`)

Редактор строит из них форму настройки плагина.

| Поле | Значение |
| --- | --- |
| `key` | Имя параметра (латиница) |
| `type` | `text`, `textarea`, `secret`, `boolean`, `number`, `select`, `entity`, `entities`, `field` |
| `label`, `description` | Подпись и пояснение (строка или `{ ru, en }`) |
| `required` | Обязательный параметр: пока он не заполнен, плагин помечен «Требует настройки» |
| `default` | Значение по умолчанию |
| `options` | Для `select`: `[{ "value": "a", "label": "Вариант А" }]` |
| `fieldOf`, `fieldTypes` | Для `field`: ключ параметра-раздела и допустимые типы полей |

Типы `entity` / `entities` дают выбор раздела (разделов) клуба, `field` — поля выбранного раздела.

`secret` — для токенов и паролей. Секреты **не попадают** в схему и в ссылку «Поделиться»: при экспорте
они записываются в `.env` сервера как `FACET_PLUGIN_<ID>_<KEY>` (дефисы → `_`, всё в верхнем регистре).
Например, секрет `token` плагина `my-bot` — `FACET_PLUGIN_MY_BOT_TOKEN`.

## Возможности (`contributes`)

| Ключ | Что делает |
| --- | --- |
| `serverHook` | JavaScript-хук PocketBase (`pb_hooks`). Выполняется на сервере клуба |
| `portalCss` | CSS, добавляемый к теме портала (виден и в предпросмотре) |
| `portalScript` | JavaScript портала (`web/plugins/<id>.js`). В предпросмотре редактора не выполняется |
| `entities` | Разделы, которые добавляются в конфигурацию при включении плагина |
| `templates` | Заготовки разделов для диалога «Новый раздел» |
| `palettes` | Дополнительные палитры оформления: `{ id, name, colors }` |
| `portalFeatures` | Встроенные возможности портала: `"csv"`, `"print"` |

### Серверный хук

Код хука — обычный [JavaScript PocketBase](https://pocketbase.io/docs/js-overview/). Особенность PocketBase:
обработчики событий **не видят переменных файла**, поэтому настройки подставляются прямо в код —
каждое вхождение `__FACET_SETTINGS__` заменяется JSON-объектом с параметрами плагина (без секретов):

```js
onRecordAfterCreateSuccess((e) => {
  const cfg = __FACET_SETTINGS__;              // { entity: "events", days: 3, … }
  const token = $os.getenv("FACET_PLUGIN_MY_BOT_TOKEN");
  console.log(`[my-bot] новая запись ${e.record.id}`);
  e.next();
}, (__FACET_SETTINGS__).entity);
```

Файл хука перегенерируется при каждом экспорте; при обновлении старые файлы плагинов удаляются, поэтому
выключенный или удалённый плагин перестаёт работать после применения обновления.

### Скрипт портала

Портал публикует объект `window.FacetPortal`:

```js
window.FacetPortal.version;        // версия Facet OS
window.FacetPortal.schema;         // конфигурация клуба
window.FacetPortal.onRender(({ path, entityId, recordId, root }) => {
  // вызывается после каждой отрисовки страницы; root — корневой элемент портала
});
```

Даты в разметке портала помечены `<time data-date="ISO-дата">` — на них удобно опираться в скриптах.

## Безопасность

Сторонний плагин выполняет код на сервере клуба (с правами PocketBase) и в браузерах посетителей портала.
Перед установкой редактор показывает, какие возможности использует плагин. Публикуйте исходный манифест,
чтобы пользователи могли его проверить, и не храните секреты в обычных параметрах — для них есть тип `secret`.

## Проверка

Манифест проверяется при установке: `id`, `name`, `version`, `description`, типы параметров и размер кода
(до 200 КБ на каждый фрагмент). Ошибки показываются в редакторе.
