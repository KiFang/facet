# Facet OS

🏛️ Open-source no-code система управления студенческим клубом, гильдией или кампусной организацией — «1С для клуба».
Соберите разделы, связи и стиль в визуальном редакторе и одной кнопкой получите готовую self-hosted систему в Docker:
база данных с панелью управления, рабочий портал с таблицами, канбаном и календарём, HTTPS и резервные копии.

## Быстрый старт

```bash
npm install
npm run dev      # редактор на http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
```

## Приложение для ПК

Facet OS можно установить как обычную программу — **Windows** (`.exe`), **macOS** (`.dmg`, Apple Silicon и Intel),
**Linux** (AppImage, `.deb`). Установщики собирает GitHub Actions (`.github/workflows/desktop.yml`):
артефакты каждой сборки — во вкладке Actions, а тег `v*` публикует их в Releases.

В приложении в меню **«Экспорт в Self-Host» → «Запустить на этом компьютере»**: система клуба (PocketBase входит в установщик)
запускается прямо на компьютере — без Docker и сервера. Портал и панель управления открываются в браузере,
по желанию — доступ с других устройств в той же Wi-Fi сети. Изменения структуры применяются как обновления
без потери данных, перед каждым делается копия, есть откат. Данные лежат в папке пользователя
(кнопка «Папка данных»).

```bash
npm run desktop                                      # собрать редактор и открыть приложение
node scripts/fetch-pocketbase.mjs linux-x64          # PocketBase для локального запуска (win-x64, mac-arm64, mac-x64)
npm run desktop:dist                                 # установщик для текущей ОС → release/
xvfb-run -a npm run test:desktop                     # e2e приложения (FACET_ELECTRON_BIN — путь к упакованному)
```

Установщики не подписаны платными сертификатами: Windows покажет «Windows защитила ваш компьютер»
(«Подробнее» → «Выполнить в любом случае»), macOS при первом запуске — правый клик → «Открыть».

## Интерфейс

Окно устроено как в строгих учётных программах:

- **Главное меню** (Файл, Правка, Вид, Данные, Плагины, Справка), **панель инструментов** и **палитра команд** (`Ctrl+K`);
- слева — **дерево конфигурации** (клуб, оформление, главная, разделы, плагины, публикация), справа — **свойства**
  выбранного узла, в центре — **рабочая область**: живой портал, схема связей разделов, JSON;
- внизу — **строка состояния**: проверка схемы, версия на сервере, локальный сервер, плагины, тема, язык;
- **настройки** (`Ctrl+,`): светлая / тёмная / системная тема, язык, подтверждения, подключение к серверу,
  резервная копия и сброс.

**Редактор данных** (`Ctrl+Shift+D`) открывается отдельным окном: таблицы разделов как в базе данных — ввод с
клавиатуры, выделение диапазонов, копирование и вставка из Excel / Google Таблиц, сортировка и поиск, выбор
вариантов и связанных записей, файлы, пометки новых / изменённых / удалённых строк, проверка ошибок и
сохранение `Ctrl+S`. Источники: **черновик** (начальные данные для экспорта), **сервер** (живая база по REST
от имени администратора) и **этот компьютер** (локальная система в приложении для ПК, вход автоматический).

**Справка** (`F1` или кнопка «Помощь») — руководство пользователя в отдельном окне: оглавление, поиск,
ссылки между разделами; кнопка «?» в свойствах открывает раздел справки про текущую страницу.

**Плагины** (`Ctrl+Shift+P`): встроенный каталог — уведомления в Telegram, автонумерация документов,
журнал изменений, печать и CSV на портале, свои стили — и установка сторонних плагинов из JSON-манифеста.
Плагин может добавлять серверные хуки PocketBase, стили и скрипты портала, разделы, шаблоны и палитры;
секреты (токены) хранятся только в `.env` сервера. Как написать плагин — [docs/PLUGINS.md](docs/PLUGINS.md),
пример — [examples/plugins/deadline-badge.json](examples/plugins/deadline-badge.json).

## Что умеет редактор

| Режим | Что доступно |
| --- | --- |
| **Простой** | Шаблоны клубов (встроенные и от сообщества), название и девиз, логотип, шрифт, палитры, форма и плотность |
| **Расширенный** | Конструктор разделов: поля, связи, вид раздела (карточки / таблица / канбан / календарь), импорт данных из CSV и Google Таблиц, главная-дашборд, токены темы |
| **Профессиональный** | Системные имена коллекций и полей (переименование без потери данных), прямое редактирование `club-schema.json` |

Во всех режимах есть **отмена/повтор** (Ctrl+Z / Ctrl+Shift+Z), **ссылка «Поделиться»** (структура и тема упаковываются в адрес),
переключение языка интерфейса и портала (**русский / English**).

Живое превью справа — **тот же код портала**, что работает на сервере (`src/portal`), только на примерах данных
или на импортированных строках.

## Экспорт: установка и обновления

**Новая установка** — zip с полной системой:

```
<club>-portal/
├── install.sh                  # установка одной командой: Docker, HTTPS по домену, запуск
├── backup.sh / restore.sh      # ручная резервная копия, восстановление, откат обновления
├── docker-compose.yml          # pocketbase + nginx + caddy (HTTPS, профиль https)
├── .env                        # администратор, порт, домен, расписание бэкапов, S3
├── club-schema.json            # слепок структуры — база для будущих обновлений
├── DEPLOY.md                   # инструкция для студентов
├── pocketbase/                 # образ, миграции (разделы, связи, импорт данных), хуки (бэкапы, S3, домен)
├── nginx/                      # портал, прокси API, защитные заголовки, CSP, лимиты запросов
├── caddy/Caddyfile             # автосертификат Let's Encrypt
└── web/                        # портал без сборки: index.html, portal.js, portal.css, логотип
```

**Обновление** — только разница с версией на сервере. Редактор сравнивает текущую схему с последней экспортированной
(или с `club-schema.json`, загруженным с сервера), показывает изменения с пометками об опасности и собирает архив
с инкрементальной миграцией. `apply-update.sh` проверяет контрольную сумму версии на сервере, делает полную
резервную копию (база + файлы), применяет обновление и подсказывает откат: `./restore.sh backups/update-…`.

Переименования полей и разделов сохраняют данные: у переименованного элемента появляется неизменяемый `uid`,
и миграция переименовывает колонку вместо удаления.

## Тесты

```bash
npm test                                   # unit: CSV, diff миграций, валидатор, ссылки, рендер портала, плагины, таблица данных
npm run test:e2e                           # Playwright: редактор, импорт, экспорт, плагины, окна справки и данных
npm run smoke:pb -- --pb ./pocketbase      # настоящий PocketBase: установка, импорт, обновление, плагины, редактор данных
npm run export -- --preset general --out ./out        # CLI экспорта (для CI и автоматизации)
```

CI (`.github/workflows/ci.yml`) дополнительно поднимает экспорт в Docker: `install.sh`, заголовки и лимиты Nginx,
`backup.sh` / `restore.sh`, `apply-update.sh` с проверкой сохранности данных и откат обновления.

## Как добавить шаблон в галерею сообщества

1. Соберите клуб в редакторе и скачайте `club-schema.json` (Pro → JSON или любой экспорт).
2. Создайте файл `src/data/templates/<имя>.json`:
   ```json
   {
     "meta": { "title": "Название", "description": "Что внутри", "icon": "Trophy", "author": "Ваш клуб" },
     "schema": { "...": "содержимое club-schema.json без editorMode" }
   }
   ```
   `icon` — одно из имён в `src/portal/icons.ts` (`ENTITY_ICON_NAMES`).
3. `npm test` проверит, что шаблон валиден. Откройте pull request.

## Структура

```
src/
├── types/schema.ts            # ClubSchema, ThemeTokens, ClubEntity, EntityField, виды, дашборд
├── store/useClubStore.ts      # Zustand + история (zundo), версия на сервере, импортированные данные
├── components/                # редактор: shell/ (меню, панели), properties/, dialogs/, ui/, превью, экспорт, импорт
├── datagrid/                  # окно редактора данных: таблица, редакторы ячеек, источники (черновик / PocketBase)
├── help/                      # окно справки: руководство ru / en и рендер разметки
├── plugins/                   # плагины: типы, встроенный каталог и хуки, сборка файлов для экспорта
├── portal/                    # портал (превью и сервер): рендер видов, контроллер, источники данных, стили
├── utils/
│   ├── exporter.ts            # архивы установки и обновления
│   ├── migrations/            # физическая модель, diff, генерация миграций, импорт строк
│   ├── csv.ts                 # CSV / Google Таблицы, определение типов, сопоставление колонок
│   ├── share.ts               # ссылка «Поделиться»
│   └── validate.ts, normalize.ts, theme.ts, relations.ts
├── i18n/                      # интерфейс редактора: ru / en
├── data/                      # пресеты и шаблоны сообщества
└── export-templates/          # Dockerfile, nginx, Caddyfile, хуки, shell-скрипты, runtime миграций
desktop/                       # Electron: главный процесс, preload, локальный сервер клуба, иконка
scripts/                       # CLI экспорта, смоук на PocketBase, загрузка PocketBase для установщика
e2e/, e2e-desktop/             # Playwright: редактор в браузере и десктопное приложение
docs/, examples/               # руководство разработчика плагинов, пример плагина
```

Стек: React + TypeScript + Vite, Electron, Tailwind CSS, Radix UI, Zustand + zundo, lucide, JSZip. Сервер клуба — PocketBase 0.25, Nginx, Caddy.
